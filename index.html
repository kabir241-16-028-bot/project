Available API Endpoints

  • POST /api/auth/signup — create an account (username, password, fullName, email)
  • POST /api/auth/login — log in and start a session (username, password)
  • POST /api/auth/logout — log out and end the session
  • GET /api/auth/me — check the current logged-in user
  • GET /api/products — list all products
  • POST /api/products — create a product
  • GET /api/categories — list categories
  • GET /api/customers — list customers
  • POST /api/orders — create an order (auto-calculates total & updates stock)
  • GET /api/orders — list all orders
  • PUT /api/orders/{id}/pay?method=CASH|CARD|MOBILE_BANKING — mark an order as paid & completed
  • GET/POST/PUT/DELETE /api/employees — manage employees
  • GET/POST/PUT/DELETE /api/suppliers — manage suppliers
  • GET/POST/PUT/DELETE /api/inventory — manage inventory items
  • GET/POST/PUT/DELETE /api/discounts — manage discounts
  • GET/POST/PUT/DELETE /api/reviews — manage reviews
  • GET /h2-console — H2 database console (JDBC URL: jdbc:h2:mem:coffeeshopdb, user: sa)
